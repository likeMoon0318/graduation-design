# 基于 Python 的群智能优化算法函数极值寻优系统

手写实现 8 种寻优算法（含 2 种传统数学规划方法与 2 种本文改进策略），在 12 个标准测试函数上
完成 **12 函数 × 8~10 算法 × 30 次独立运行 × 3 个维度** 的大规模对比实验，
用 Friedman / Wilcoxon 检验给出统计学支撑的结论，并提供一个可现场演示的动画式寻优过程演示器。

---

## 一、快速开始

```bash
cd 项目二_函数极值寻优

# 1) 一键复现全流程（实验 -> 统计检验 -> 参数敏感性 -> 出图）
python run_all.py

# 2) 启动寻优过程演示器（答辩现场演示用）
python src/simulator.py
```

只想复用已有实验数据时：

```bash
python run_all.py --from analyze     # 实验数据已存在，只做统计与出图
python run_all.py --force            # 忽略断点，实验全部重跑
python run_all.py --list             # 查看阶段列表
```

依赖：`numpy scipy pandas matplotlib seaborn joblib`，演示器需要标准库 `tkinter`。

## 二、实验协议（可复现性设计）

| 项目 | 设置 |
|---|---|
| 测试函数 | 12 个标准函数：4 个单峰、5 个多峰、3 个低维多峰（仅 2 维） |
| 维度 | 2 维（可视化）、10 维（主实验）、30 维（可扩展性） |
| 算法 | GA、PSO、APSO、DE、GWO、SA、BFGS、NM 共 8 种；2 维额外加入 GRID、RANDOM 两种基线 |
| 独立运行 | 每个（算法 × 函数 × 维度）组合重复 30 次，随机种子固定为 1..30 |
| 统一预算 | 每个算法 300 代 × 50 个体 = **15000 次函数评价**（传统方法按迭代次数计） |
| 记录内容 | 每一代的最优值与群体均值 → `data/raw/runs_history.csv`（62.6 万行） |
| 成功判据 | \|f_best − f*\| < 1e-2 |
| 复现命令 | `python run_all.py`（实验部分通过 joblib 并行，6 进程约 20 秒完成 7920 次寻优） |

**为什么用 30 次独立运行**：单次运行的结果受随机初始化与随机算子影响极大，
只有重复实验 + 统计检验才能区分"算法真的更好"和"运气好"。本项目所有结论都建立在
Friedman 检验（整体差异）与 Wilcoxon 符号秩检验（两两差异，Holm 校正）之上。

## 三、算法清单

| 层次 | 算法 | 关键设计 |
|---|---|---|
| 传统方法 | BFGS（L-BFGS-B） | 拟牛顿法，带边界投影，依赖梯度信息 |
| 传统方法 | Nelder-Mead | 单纯形直接搜索，无需梯度 |
| 群智能 | GA 遗传算法 | 实数编码、锦标赛选择、SBX 交叉、多项式变异、精英保留 |
| 群智能 | PSO 粒子群 | 收缩因子版本（w=0.729, c1=c2=1.49445），越界维度速度清零 |
| 群智能 | DE 差分进化 | DE/rand/1/bin，贪婪选择 |
| 群智能 | GWO 灰狼优化 | alpha/beta/delta 三级头狼引导，收敛因子 a 线性衰减 |
| 邻域搜索 | SA 模拟退火 | **多链并行**：pop_size 条独立马尔可夫链，温度按目标函数值域自适应标定 |
| 改进策略 | APSO 自适应权重粒子群 | 惯性权重 0.9→0.4、c1 递减、c2 递增，探索与开发动态平衡 |

> 关于 SA：经典单点串行 SA 在同等评价预算下无法与群体算法公平对比，
> 因此实现为多链并行版本，每代每条链做一次邻域扰动，保证每代评价次数与群体算法一致。

## 四、主要实验结论

### 4.1 整体差异显著

Friedman 检验在三个维度上均拒绝"各算法性能相同"的原假设：

| 维度 | 算法数 k | 区组数 N | Friedman χ² | p 值 | Nemenyi 临界差值 CD |
|---|---|---|---|---|---|
| 2 维 | 10 | 360 | 2258.38 | < 1e-300 | 0.714 |
| 10 维 | 8 | 270 | 1030.02 | 3.94e-218 | 0.639 |
| 30 维 | 8 | 270 | 1060.38 | 1.08e-224 | 0.639 |

### 4.2 平均排名（Friedman 秩统计量，1 为最优）

| 排名 | 2 维 | 10 维 | 30 维 |
|---|---|---|---|
| 第 1 | DE（1.81） | APSO（2.54） | **GWO（2.22）** |
| 第 2 | APSO（2.15） | GWO（3.09） | APSO（3.49） |
| 第 3 | PSO（3.14） | PSO（3.41） | PSO（3.55） |

### 4.3 成功率与"维度灾难"

以 \|f − f*\| < 1e-2 为达标判据的 30 次运行成功率：

| 算法 | 2 维 | 10 维 | 30 维 |
|---|---|---|---|
| GWO | 96% | 54% | 51% |
| DE | 100% | 47% | 3% |
| PSO | 98% | 46% | 3% |
| APSO | 100% | 46% | 1% |
| GA | 95% | 13% | 0% |
| BFGS | 58% | 32% | 35% |
| SA | 59% | 0% | 0% |
| NM | 51% | 0% | 0% |
| 随机搜索（基线） | 32% | — | — |
| 网格搜索（基线） | 42% | — | — |

三个可以直接写进结论的规律：

1. **传统方法在单峰可微问题上依然强势**：Rosenbrock 函数（10 维）上 BFGS 的误差中位数为 2.07e-10，
   优于除它之外的所有群体智能算法；但在 Rastrigin 上 BFGS 的中位误差高达 106，
   与 Nelder-Mead 一同垫底——**梯度法一旦遇到多峰地形就会停在局部最优**。
2. **GWO 的高维鲁棒性最好**：10 维下在 Sphere、Rastrigin、Ackley、Schwefel 2.22 上
   30 次运行全部达标（成功率 100%），30 维下仍保持 51% 的整体成功率；
   但在 Schwefel 2.26 上它是全场最差（误差中位数 2.6e+03），说明**没有普适最优算法
   （No Free Lunch）**。
3. **SA 的维度敏感性最强**：2 维下 59% 达标，10 维直接降到 0%。
   邻域搜索在高维空间中"走不动"，这是维度灾难最直观的证据。

### 4.4 逐函数最优算法（10 维，误差中位数）

| 函数 | 最优算法 | 最差算法 |
|---|---|---|
| Sphere | GWO（5.4e-46） | NM（4.8e+03） |
| Rosenbrock | **BFGS（2.1e-10）** | NM（7.8e+05） |
| Rastrigin | GWO（0） | NM（1.1e+02） |
| Ackley | GWO（4.0e-15） | NM（19.8） |
| Griewank | GWO（0） | NM（33.8） |
| Levy | APSO（9.0e-20） | NM（25.6） |
| Schwefel 2.22 | GWO（1.1e-26） | NM（36.2） |
| Dixon-Price | APSO（0.67） | NM（1.7e+03） |
| **Schwefel 2.26** | **DE（327）** | GWO（2.6e+03） |

Schwefel 2.26 是全场最难的函数：最优解位于搜索空间边界附近，且与次优吸引域相距极远，
**所有算法 30 次运行无一达标**，最好成绩（DE，误差 327）与理论最优仍相差两个数量级。

### 4.5 两两检验与基线对比

- Wilcoxon 符号秩检验共 101 组两两比较，经 Holm 校正后 **92 组差异显著（91%）**。
- 2 维下与基线方法的对比（同等 15000 次评价预算，误差取 30 次运行的中位数）：

  | 方法 | 全部函数合并的 log10(误差) 中位数 | 达标率 |
  |---|---|---|
  | 网格搜索 GRID | -0.59 | 41.7% |
  | 随机搜索 RANDOM | -0.89 | 32.5% |
  | 8 种群智能 / 传统算法 | **-9.32** | 82.1% |

  逐函数看，**12 个函数上智能算法全部优于两种基线**，误差改进倍数从
  2.1×10¹²（Six-Hump Camel）到直接收敛到机器精度 0（Griewank、Rastrigin、
  Rosenbrock、Beale、Himmelblau、Schwefel 2.26 等）：在相同评价次数下，
  智能算法的精度比"无智能"的随机搜索高出 **8~300 个数量级**。

### 4.6 参数敏感性（10 维，4 个代表性函数 × 10 次重复）

| 算法-参数 | 最佳取值 | 最差取值 | 极差倍数 |
|---|---|---|---|
| PSO-惯性权重 w | 0.729（3.19） | 0.9（6.08e+03） | **1909×** |
| DE-缩放因子 F | 0.6（2.54） | 0.2（2.41e+03） | 948× |
| SA-降温半径指数 | 0.2（1.33e+03） | 0.8（2.68e+05） | 202× |
| GA-变异概率倍数 | 0.5（3.38） | 5.0（1.21e+02） | 36× |
| DE-交叉概率 CR | 0.9（2.66） | 1.0（78.3） | 29× |
| PSO-学习因子 c1 | 1.49445（3.19） | 2.5（78.2） | 25× |
| GA-交叉概率 pc | 1.0（3.70） | 0.75（5.95） | 2× |
| GWO-种群规模 | 2 倍（1.59） | 0.5 倍（1.80） | 1.1× |

结论：**参数选择对性能的影响可以跨越 3 个数量级**（PSO 的 w 从 0.729 提到 0.9 直接让误差
放大 1909 倍）；而 GWO 对种群规模几乎不敏感，鲁棒性来自算法结构本身。

## 五、寻优过程演示器

`python src/simulator.py` 启动后：

- **问题设置**：12 个测试函数下拉切换，自动显示等高线（高维时给出固定其余维度的切片）、
  理论最优位置、搜索范围与函数特点说明
- **算法设置**：选择算法后自动出现该算法的可调参数（交叉概率、变异概率、惯性权重、
  学习因子、缩放因子、邻域步长、降温指数等），另可设置种群规模、迭代次数、随机种子
- **动画演示**：点击「开始寻优」后，白色散点为当前种群、橙色圆圈为当前最优个体、
  橙色折线为历代最优位置的移动轨迹；右侧同步绘制对数误差收敛曲线
- **实时读数**：本次最优值、与理论最优的绝对误差、是否达标、函数评价次数、
  运行耗时、收敛代数、最优解向量
- **多算法对比**：点击「加入对比」把当前结果累积到对比表，并把它的收敛曲线以虚线叠加在同一张图上
- **导出**：一键导出当前画面为 300dpi PNG

## 七、复现说明

```bash
python run_all.py --force     # 从零开始：约 60 秒完成全部实验、统计与出图
python run_all.py             # 有断点则自动跳过已完成任务
```

实验中断后再次执行 `python run_all.py` 会自动复用 `data/raw/parts/` 中已完成的任务，
只补跑缺失部分；需要完全重跑时加 `--force`。
