# 专业综合设计：两个独立项目

本目录包含两个完全独立、可分别提交与答辩的专业综合设计项目。两个项目各有独立的数据、
代码、图表、报告与图形界面，互不引用。

| | 项目一 | 项目二 |
|---|---|---|
| 题目 | 基于 Python 的电商销售数据分析与可视化系统 | 基于 Python 的群智能优化算法函数极值寻优系统 |
| 方向 | 数据分析与可视化实践 | 算法设计及应用 |
| 规模 | 28.9 万条订单、19,524 名客户、18 张图表、23 张结果表 | 12 个测试函数、8 种算法、7,920 次寻优运行、17 张图表 |
| 图形界面 | 交互式看板（16 种图表 + 多维筛选） | 寻优过程动画演示器（含多算法对比） |
| 报告 | 专业综合设计报告（27 页，Word） | 专业综合设计报告（24 页，Word） |
| PPT | 16 页答辩 PPT + 讲稿与预测问题 | 16 页答辩 PPT + 讲稿与预测问题 |

---

## 一、快速开始

```bash
# 项目一：一键复现全流程 -> 启动看板
cd 项目一_电商销售数据分析与可视化
python run_all.py
python src/dashboard.py

# 项目二：一键复现全流程 -> 启动寻优演示器
cd ../项目二_函数极值寻优
python run_all.py
python src/simulator.py
```

两个项目的完整说明见各自目录下的 `README.md`。

## 四、仍需你完成的三件事

1. **填写封面信息**：两份报告的封面留有「姓名 / 学号 / 班级 / 指导教师」，
   两份 PPT 的封面同样留空。可直接在 Word / PowerPoint 中填写，
   也可以改 `report/build_report.py` 中的封面信息后重新生成。
2. **核对学校模板**：本报告按 A4、正文宋体小四、1.45 倍行距排版。
   若学校有指定模板或字数要求，把模板发我，我按模板重排（只需改 `report/docx_helpers.py`
   中的页面与字体参数，正文内容不受影响）。
3. **亲手跑一遍演示**：两个界面各启动一次，熟悉操作路径。
   建议的演示动线写在各自的 `README.md` 与讲稿中。
