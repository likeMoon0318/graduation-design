# 基于 Python 的电商销售数据分析与可视化系统

一个从**数据生成 → 清洗 → 特征工程 → 探索性分析 → 统计检验 → 客户分群 → 建模 → 可视化 → 交互式看板**
的完整数据分析项目。全部数据由程序仿真生成，随机种子固定，**结果完全可复现**。

---

## 一、快速开始

```bash
cd 项目一_电商销售数据分析与可视化

# 1) 一键复现全流程（生成数据、清洗、分析、建模、出图）
python run_all.py

# 2) 启动交互式看板（毕业答辩演示用）
python src/dashboard.py
```

只想复用已有数据、不重新生成原始数据时：

```bash
python run_all.py --from clean        # 从清洗阶段开始，复用已有 data/raw/orders_raw.csv
python run_all.py --skip generate     # 跳过数据生成
python run_all.py --list              # 查看全部阶段
```

依赖：`numpy pandas scipy scikit-learn matplotlib seaborn openpyxl`，图形界面需要标准库 `tkinter`。

## 二、数据从哪来（答辩必问）

原始数据不是网上抓取，而是用**带业务机理的仿真模型**生成：`src/data_generator.py`

| 仿真维度 | 建模方式 |
|---|---|
| 全年趋势 | 对数增长基线，全年约 +18% |
| 季节波动 | 夏（618）、冬（双 11 / 双 12）双峰高斯叠加 |
| 周周期 | 周五—周日下单量上浮，周一最低 |
| 大促脉冲 | 7 个真实档期（年货节、38 节、618、818、国庆、双 11、双 12）逐日脉冲 |
| 时段分布 | 早间 / 午间 / 晚间三峰小时权重 |
| 地区梯度 | 13 个省份按消费能力加权（广东、北京、上海居前） |
| 渠道漂移 | APP 与小程序占比全年上升，网页与线下门店下降 |
| 品类结构 | 8 大品类的价格采用对数正态分布，退货率、评分与价格存在相关性 |
| 客户行为 | 2 万名客户，活跃度呈幂律分布，会员等级影响客单价 |
| **刻意注入的脏数据** | 重复订单 0.6%、金额字符串格式混乱 2%、缺失值（省份/城市 2%、评分 8%）、逻辑异常（数量与金额不匹配）、异常值（0.54%）、文本前后空格与大小写不一致 |

注入清单落在 `data/raw/injection_log.json`，清洗时逐项对照处理，
`results/tables/data_quality_report.csv` 给出"问题数量 → 处理方式"的完整对照表。

最终得到 **289,310 条**订单记录（2025-01-01 ~ 2025-12-31），全年销售额 **3.27 亿元**。

## 四、分析结论速览

**1. 销售结构高度集中**

手机数码与家用电器两个品类贡献 **69.0%** 的销售额（帕累托图显示前 3 个品类累计占比超过 82%），
是典型的"少数品类贡献主要营收"结构；图书文娱销售额占比仅 0.56%。

**2. 大促"以价换量"特征明确**

大促期间订单量显著高于平日，但客单价显著**低于**平日（Welch t 检验 p < 0.001，Cohen's d = -0.11），
说明促销主要靠折扣拉动销量，而非提升单笔金额。

**3. 品类决定退货风险**

卡方独立性检验拒绝"品类与退货相互独立"（χ² = 22659, df = 7, p < 0.001，Cramér's V = 0.280，中等强度关联）。
服饰鞋包退货率 **24.0%**，远高于图书文娱的 1.7%，是退货治理的首要对象。
相比之下渠道与退货基本无关（p = 0.055，不显著）——**退货是"商品属性"问题，而不是"下单入口"问题**。

**4. 评分是退货的先行信号**

退货订单平均评分 4.07，未退货订单 4.35（Mann-Whitney U 检验 p < 0.001，rank-biserial r = 0.201）。
评分 1 分的订单退货率 **42.1%**，评分 5 分仅 **6.9%**，退货风险随评分单调下降。

**5. 客户分层清晰，可差异化运营**

KMeans（k = 4，依据轮廓系数与 SSE 拐点选择）把 19,524 名客户分成四群：

| 分群 | 客户数 | 占比 | 平均消费额 | 特征与策略 |
|---|---|---|---|---|
| 核心价值客户 | 3,736 | 19.1% | 29,035 元 | R 小 F 高 M 高，重点维护、专属客服 |
| 稳定活跃客户 | 6,112 | 31.3% | 26,545 元 | 近期活跃、频次高，交叉销售提升客单 |
| 一般维持客户 | 6,861 | 35.1% | 7,586 元 | 消费低频，用满减券刺激复购 |
| 流失预警客户 | 2,815 | 14.4% | 1,338 元 | R 大于 120 天，短信/推送召回 |

**6. 订单金额可解释性良好**

岭回归（特征含单价、数量、折扣、品类、渠道、地区、会员等级、促销标记等 30 维）对 log(订单金额+1)
的测试集 R² 达 **0.797**；Spearman 检验显示单价与订单金额强相关（ρ = 0.913），单价是订单金额的第一驱动因素。

**7. 退货可预测，但需权衡召回**

类别加权逻辑回归预测退货（19 维特征）测试集 AUC = **0.759**，召回率 68.8%——
适合作为"退货风险预警名单"辅助人工干预，而非自动决策。

## 五、交互式看板

`python src/dashboard.py` 启动后：

- **左侧筛选区**：日期范围下拉、地区 / 渠道 / 品类 / 会员等级多选列表（Ctrl 或 Cmd 多选）
- **顶部指标卡**：订单量、销售额、客单价、退货率、消费客户数，随筛选实时刷新
- **图表区**：16 种图表下拉切换，支持工具栏缩放、平移、保存
- **明细区**：筛选结果分页预览（每页 50 条）
- **导出**：「导出筛选结果 CSV」导出全量筛选结果；「导出当前图表 PNG」导出 300dpi 图片

看板内置的 16 种图表：销售额趋势、下单时段热力图、品类帕累托图、渠道结构环形图、渠道趋势堆叠面积图、
地区销售额排行、城市销售额排行、订单金额分布、各品类金额箱线图、相关性热力图、单价与金额散点图、
评分与退货率、大促效应对比、重点地区月度趋势、会员等级客单价、时段销售分布。
